# Chatting 💬

A modern real-time chat application designed for seamless and interactive communication. This project provides instant messaging functionality with a responsive user interface, secure authentication, and scalable backend architecture.

---

## 🚀 Features

- 🔐 User Authentication & Authorization
- 💬 Real-Time Messaging
- 🟢 Online/Offline User Status
- 📱 Fully Responsive Design
- ⚡ Fast and Smooth UI
- 🔔 Instant Message Updates
- 🧩 Scalable Backend Architecture
- 🎨 Clean and Modern Interface

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Real-Time Communication
- Socket.io

### Authentication
- JWT (JSON Web Token)

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/shubham-kumar145/Chatting.git
cd Chatting
```

---

## 📦 Install Dependencies

### Frontend

```bash
cd frontend
npm install
```

### Backend

```bash
cd backend
npm install
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend folder and add:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```

---

## ▶️ Run the Project

### Start Backend

```bash
cd backend
npm run dev
```

### Start Frontend

```bash
cd frontend
npm run dev
```

---

## 🌐 Application Workflow

1. User registers or logs in
2. Authentication token is generated
3. Users can send and receive messages instantly
4. Real-time updates are handled using Socket.io
5. Messages are displayed dynamically without page refresh
